One line, under 200 characters, that renames a planet of our solar system and gives the why in the same breath. This entry renames Saturn **The Bath Toy**: its mean density is 0.687 g/cm³, so it is the only planet that would float in a tub, and Cassini measured ring material raining into the planet, so the toy is dissolving in the water. `main.ts` holds the line, checks it against the gate (UTF-8, 1 to 200 code points, one line, not blank) and writes it to `/output/entry.txt`.

## Run it

```sh
OUTPUT_DIR=./out node main.ts
```
